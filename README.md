# LUT Player

一个面向离线 HDR 电影资源的跨平台网页播放器，支持通过 3D LUT 恢复原始色彩细节，同时提供配套的 FFmpeg 转码 GUI 工具。

## 项目简介

许多离线下载的 HDR 版本电影资源，其色彩空间为 **Rec.2020**，伽马曲线也与目前主流的 sRGB 显示设备不匹配。浏览器原生的 `<video>` 标签在播放这类视频时，会自动尝试进行一次 HDR → SDR 转换，导致完整动态范围被截断，画面细节丢失。

本项目的网页播放器会提取视频的原始画面，并允许用户加载自己的 3D LUT（`.cube` 文件）来手动恢复色彩，从而获得更完整的细节表现。播放器本身跨平台，理论上任何有现代浏览器的设备都能运行。

同时，项目在 Releases 中提供了一个基于 Tauri 的 FFmpeg GUI 工具（`ffmpeg_gui`），用于将各类视频快速转换为浏览器兼容性最好的 MP4 容器，方便在网页播放器中直接使用。

## 功能特性

### 网页播放器

- **WebGL2 渲染**：使用 WebGL 2.0 进行视频画面渲染，支持 3D LUT 实时滤镜。
- **3D LUT 支持**：加载 `.cube` 格式的 3D LUT 文件，实时切换，不重新加载视频。
- **内嵌字幕解析**：支持解析 MP4 内嵌文本字幕（`tx3g`、`wvtt`），自动提取字幕轨并显示。
- **外部字幕**：支持加载 `.srt` / `.vtt` 外部字幕文件。
- **播放列表**：支持多视频播放列表，可添加、切换、清空。
- **拖放导入**：
  - 拖入单个视频：直接添加到列表并立即播放。
  - 拖入多个视频：仅追加到播放列表，不打断当前播放。
  - 拖入单个 `.srt` / `.vtt`：立即启用外部字幕，并关闭内嵌字幕。
  - 拖入单个 `.cube`：自动载入并开启 LUT 滤镜。
  - 拖入多个字幕或 LUT 文件时，操作会被忽略。
- **键盘快捷键**：
  - `空格`：播放 / 暂停
  - `←` / `→`：快退 / 快进 5 秒
  - `↑` / `↓`：音量 +5% / -5%
  - `F`：进入 / 退出全屏
  - `M`：静音切换
- **状态记忆**：关闭页面后，会自动记住以下状态，重新打开时恢复：
  - 播放列表元数据
  - 当前播放的视频索引与时间戳（需重新选择同一视频文件后自动跳转）
  - 音量
  - 字幕字号
  - LUT 开关、LUT 文件名与 LUT 内容（存储在 IndexedDB）
  - 外部字幕内容与文件名（存储在 IndexedDB）
  - 内嵌字幕选择

### FFmpeg GUI（Releases 中提供）

- 基于 Tauri 构建，用于调用 `ffmpeg.exe` 和 `ffprobe.exe`。
- **功能**：将视频转换为 MP4 容器。
- **自动流选择**：
  - 选择分辨率最高的视频流。
  - 选择声道数最多的音频流。
  - 保留所有文本类字幕流（图片类字幕流会被舍弃，因为 MP4 不支持图片类字幕）。
- **音频转 AAC**：
  - 许多影视资源使用 DTS、EAC3 等音频编码，因授权原因浏览器无法播放。
  - AAC 是 MP4 容器官方指定的音频编码，兼容性最好。
- **默认音频参数**：380 kbps、fast 模式、立体声。
  - 强制立体声并限制码率上限，是因为更多声道数和更高码率会严重拖累编码速度。
  - 该默认参数可实现 60 倍以上的编码速度。
- **为什么不做成 exe 的 LUT 播放器？**
  - exe 播放器只能在 Windows 上运行，若要支持其它平台，开发成本会大幅飙升。
  - 网页播放器则是跨平台的，理论上任何有浏览器的地方都能运行。
- **FFmpeg 版本**：9.0.2
  - 原始下载路径：[https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-full.7z](https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-full.7z)

## 安装与使用

### 网页播放器

1. 直接访问：[https://Xeserved.github.io/lut-player/](https://Xeserved.github.io/lut-player/)
2. 点击“添加视频”选择本地视频文件，或将视频文件直接拖入页面。
3. 在“设置”中可加载外部字幕、调整字幕字号、加载 3D LUT 文件。
4. 使用键盘快捷键或界面按钮控制播放。
5. 关闭页面后重新打开，播放列表和设置会自动恢复；选择相同视频文件后可继续上次的播放进度。

### FFmpeg GUI

1. 前往项目的 [Releases](https://github.com/Xeserved/lut-player/releases) 页面。
2. 下载最新的 `ffmpeg_gui` 安装包（`.exe`）。
3. 安装后运行，界面中调用 `ffmpeg.exe` 和 `ffprobe.exe` 进行转码。
4. 安装包内已包含 FFmpeg 9.0.2，你也可以自行替换为其它版本的 `ffmpeg.exe` 和 `ffprobe.exe`。

## 注意事项

- **视频文件无法自动恢复**：由于浏览器安全限制，关闭网页后无法自动重新读取本地视频文件。重新打开页面后，播放列表会显示为“待重新选择”，你需要再次选择或拖入相同文件，播放器会自动匹配并跳转到上次的时间戳。
- **LUT 与外部字幕的存储**：LUT 文本和外部字幕内容会保存在浏览器的 IndexedDB 中，清理浏览器数据会导致这些内容丢失。
- **许可证**：本项目采用 MIT License。FFmpeg 组件有其独立的许可证，详见 FFmpeg 官方说明。
- **浏览器兼容性**：建议使用最新版的 Chrome、Edge、Firefox 或 Safari。WebGL 2.0 和 IndexedDB 是播放器正常运行的必要条件。
